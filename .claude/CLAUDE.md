## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (`canyon-velvet/email-agent`), managed with the `gh` CLI. See `.claude/docs/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `.claude/docs/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `.claude/docs/domain.md`.
